# Online Retail Sales Analysis Using Python

## Project Overview

This project analyzes online retail transaction data using Python to identify sales trends, top-performing products, customer purchasing patterns, and revenue distribution across countries.

## Objectives

* Explore and understand retail transaction data.
* Clean the dataset and handle missing values and duplicate records.
* Calculate revenue for each transaction.
* Identify the top 10 products by revenue.
* Analyze revenue across different countries.
* Examine monthly sales trends.
* Identify the top 10 customers by total spending.

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

The project uses the Online Retail dataset from the UCI Machine Learning Repository. It contains transaction records from a UK-based online retailer.

Dataset source: UCI Machine Learning Repository — Online Retail.

## Project Workflow

1. Data loading and exploration.
2. Data cleaning and preparation.
3. Feature engineering and revenue calculation.
4. Sales KPI analysis.
5. Product and country revenue analysis.
6. Monthly sales trend analysis.
7. Customer spending analysis.
8. Data visualization and export of results.

## Key Outputs

* Top 10 products by revenue.
* Top 10 countries by revenue.
* Monthly revenue trend.
* Top 10 customers by revenue.
* Exported CSV files containing analysis results.

## Business Value

The analysis can help an online retailer understand sales performance, identify high-revenue products and markets, and explore customer purchasing patterns to support business decisions.
